# TEDxUniversity of Bamenda

The TEDxUniversity of Bamenda event site, built with React, Vite, and Tailwind CSS v4.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Install

```bash
npm install
```

To configure the Laravel API base URL, copy `.env.example` to `.env` and update `VITE_API_URL` as needed. Checkout and code redemption currently use local stubs and make no network requests.

## Run

```bash
npm run dev
```

## Build

```bash
npm run build
```
